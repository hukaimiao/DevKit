# DevKit

一个基于 Vue 3 和 Vite 的浏览器开发者工具箱。工具输入和处理结果留在当前页面。

## 本地启动

需要 Node.js 18+。

```sh
npm ci
npm run dev
```

访问终端显示的 localhost 地址。生产构建使用 `npm run build`，输出到 `dist/`。SHA、UUID 与剪贴板功能需要 localhost 或 HTTPS。

## 操作

- 使用 `Ctrl+K` / `⌘K` 聚焦搜索，回车打开第一个匹配工具。
- 使用 `Ctrl+Enter` / `⌘Enter` 执行当前工具的第一个操作。
- 输入区可一键载入示例，结果区支持复制。
- 点击卡片上的星标收藏工具，可从「我的收藏」访问。收藏保存在当前浏览器。
- JWT 工具仅解析三段式令牌的标头和载荷，结果明确标记签名未验证。

## 工具目录

- 代码与配置：JS、TS、HTML、CSS、Markdown、SQL 格式化，YAML / JSON、CSV / JSON 转换，JSON 键排序和文本差异。
- 网络与时间：IP、CIDR、Cron、时区、URL 结构、时间戳。
- 接口调试：JWT、HTTP 标头和 URL 查询参数解析。
- 生成与转换：二维码 PNG、密码、随机字节、UUID、城市拼音分组、UTF-8 Hex 和 Unicode 转义。
- 文本与计算：正则筛选、命名转换、行编辑、列表转换、SemVer 比较、存储和耗时换算。

## 语言和 Properties

- 页面提供简体中文、English 和「跟随浏览器」。默认从浏览器的语言顺序中选择首个受支持的语言，无匹配时使用 English。手动选择保存在当前浏览器。
- YAML ↔ Properties 支持 Java Properties 的注释、续行及转义。嵌套键和数组索引使用点号展开。反向转换把点号恢复为映射层级，并保留字符串值与数字键，避免猜测数组或值类型。

## 进阶工具

- 数据与配置：JSON Pointer 查询、JSON 结构对比、单行 `.env` 转 JSON、XML 语法校验。
- 接口、网络、校验：Cookie 解析、常见 HTTP 状态码、Base64URL、HMAC SHA-2、CRC32、CIDR 归属、反向 DNS 名称生成。
- 计算与前端：ISO 日期间隔、整数范围、WCAG 颜色对比度。
- Git 命令速查、cURL 转 JavaScript Fetch / Python Requests、JSON 生成 TypeScript 类型。
- 本地文件 SHA-2 哈希与图片压缩，分别支持最大 128 MiB 和 40 MiB。图片支持调整质量、最长边并下载 WebP / JPEG。

Cron 支持每天、每周、每月、分钟间隔和自定义字段。可以生成对应格式的表达式，也可以将已有表达式反解析到时间选择器。预览可指定时区和起算时间。

- Cron 可切换五段 Linux Cron 和六／七段 Quartz。Quartz 支持 1970–2099 年的指定年份、列表、范围或步长，以及每月最后一天和每月第几个星期几。预览使用所选时区。
- 「生活工具」含中国大陆居民工资薪金累计预扣估算、折扣计算和固定利率房贷估算。工资工具采用常规每月 5000 元减除费用口径，并在页面提供税务总局政策链接。

### 工资个税

- 全年与年终奖页按 2026 年 12 个月同一雇主固定工资估算。北京、上海支持按上下半年城市标准估算个人缴费，其他城市可输入工资单上的个人社保和公积金。可覆盖缴费基数及选择公积金比例。
- 比较符合条件的全年一次性奖金单独计税与并入综合所得，提供逐月到手明细和有差额时的汇算调整估算。原有「单月累计预扣」页继续用于录入当期及历史实际数。
